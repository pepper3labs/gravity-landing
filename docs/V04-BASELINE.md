# v0.4 稳定基线审计（v0.5 开发前）

Git 标签：v0.4-stable。当前 v0.4 在修改前通过全部 18 项测试。
双指输入分别维护 pointerId 集合；推进与旋转可同时操作，取消/松手/失焦会清理。
支架使用左右独立接触点、弹簧阻尼、接触点线速度（含角速度）和独立耐久；断裂移除接触点。
主体使用独立四点接触，致命冲击低于支架，单腿可依靠真实轻微主体接触迫降。

| 基线参数 | 值 |
| --- | --- |
| 固定步 | 1/120 s |
| 重力（原关卡表面） | 30 |
| 主推力 / 旋转加速度 | 72 / 3.8 |
| 角阻尼（按住 / 松开） | 0.7 / 2.8 |
| 角速度上限 | 1.65 rad/s |
| 燃料 / 主喷耗油 / 姿态耗油 | 100 / 2.8/s / 0.18/s |
| 质量 / 转动惯量 | 1 / 210 |
| 支架局部位置 | x=±12, y=23 |
| 弹簧 / 阻尼 | 260 / 23 |
| 支架安全 / 断裂冲击 | 18 / 42 m/s |
| 支架损伤系数 | 超出安全冲击每 m/s 扣 3 |
| 主体致命冲击 / 穿透上限 | 14 m/s / 9 |
| 普通着陆下降 / 横移 / 角度 | <9 / <7 m/s / <0.2 rad |
| 普通角速度 / 稳定时间 | <0.25 rad/s / 1.1 s |
| 迫降下降与横移 / 角度 | <4 m/s / <0.85 rad |
| 迫降角速度 / 稳定时间 | <0.35 rad/s / 1.8 s |

本轮不调整主推力、耗油、转向、角阻尼、角速度上限、几何尺寸、固定时间步。
每关通过显式配置改变星球重力、初始燃料、支架耐冲击/缓冲倍率、平台宽度与着陆条件。
原 LEVEL 和 CONFIG 作为回归基准保留，原 18 项测试保持原样。
