# v0.7 第十五关：逆向绕行

2026-10-15，基于 70de2e6，开发版仍为 0.7.0-dev.1；当前十五关、45 星。

## 设计与结果

第三章首关 reverse-arc：从上方发射台向左进行逆时针转移，越过固定岩脊及竖直巡游岩体，从外侧抵达左下方 76m 平台。学习点是区分机头与惯性方向，并在反向航行时提前制动；保持同一飞船推力与转向规则，没有新增随机机制或修改旧关。

配置：重力 14、初始燃料 120，冰面外观，巡游周期 26 秒；验证路线半径 750，从 -90° 到 -200°。自动驾驶真实输入完成 14,457 步 / 120.47s，余油 82.74（68.9%），双腿无损、主体无撞击、三星。这些是机器模拟结果，不是玩家平均表现。
