# 界面结构与关键布局方案

## 2026-10-23 最新确认：手机竖屏优先

以手机竖屏触控为首发设计与验收基准（390×844，覆盖360×640、430×932），桌面兼容。横屏仅作兼容检查，不再作为主设计方向或首发P0门槛。下文历史横屏布局、双列示意及横屏任务要求均以本条为准。

菜单遵循手机操作：内容纵向滚动，每页一个明确主动作，主要继续/出发/重试位于内容下方的拇指可达区域；长页使用不遮挡内容的底部操作区，保留系统底部安全距离。返回固定在左上且逐层返回，危险动作与继续分开，广告作为次级可选操作。目标至少48×48 CSS像素，不依赖悬停、精细点按或横向拖动。现有飞行HUD、双指按钮与飞行镜头保持；不能把菜单尺寸规范套用成HUD改版。


## 2026-10-23 用户评审更新：保留当前飞行 HUD

用户明确认可现有飞行HUD。后续保留dev.25的遥测项目、信息层级、位置、视觉样式、操作按钮及提示方式，不实施本轮提出的HUD重排、精简或新布局。默认不调整飞行镜头。菜单、选关、远征、暂停、结算与设置继续按方案评审。

横屏适配和四边安全区仍须验证，但不能以此擅自替换已认可的HUD；若实测发现必须调整HUD或镜头才能适配的冲突，单独呈现问题和最小改动方案。触控释放、模态输入隔离、传感器异常及返回路径可以继续审查；具体实现仍在后续阶段。


设计稿而非已实现页面。配套 [静态线框板](wireframes.html) 展示结构；其中数值是布局示例，不是玩家档案或线上成绩。线框可独立打开，不访问存档、不联网、不请求广告。

## 全局布局

- 竖屏参考390×844 CSS像素，最小验证360×640；首页、关卡详情、远征与结算均采用纵向信息层级。先看状态，再做主要动作，不缩小整页来塞内容。
- 桌面1366×768/1920×1080：扩大场景与列表，不把中间限制成手机壳；键鼠提示按输入设备切换。超宽屏1440×600验证菜单空间利用；飞行HUD维持现状，适配冲突单独评审。
- 竖屏360×640、390×844、430×932为主验收矩阵；横屏只保留可访问和返回能力，不要求旋转手机。
- 四边安全区内的有效矩形分为顶栏、主体、操作区；星空可延伸到安全区外，文字与交互不可以。
- 菜单横屏顶栏可参考48px；飞行HUD与操作区不套用本次新尺寸，保留当前实现。
- 镜头按当前实现保留；若横屏实测发现取景问题，单独提出调整，不作为已批准的连带改动。

## 01 主界面：机库 / 下一次航行

```text
┌ 安全区 ───────────────────────────────────────────┐
│ 引力盲航                         金币 180   设置 ⚙ │
│                                                   │
│        飞船 / 星球 / 安静星空      下一次主线        │
│        （复用当前场景）           第04关 · 航线名   │
│                                 [继续主线 →]      │
│                                                   │
│               [主线航线] [连续远征·3/30] [每日挑战] │

```

新档主CTA“启程 · 第1关”；熟练玩家显示准确航线，不用“继续”暗示恢复不存在的飞行现场。有远征存档时卡片标进度与“未发射，可继续”。主线仍可访问，不把玩家自动送入远征。练习在主线页和操作帮助中，诊断工具不占首页。

## 02 关卡选择：章节航线图 + 选中任务

```text
│ ‹ 主菜单    主线航线   第一章 / 第二章 / …   18/90星 │
│ [01★★☆]──[02★★★]──[03★☆☆]   │ 第04关 · 目标说明     │
│ [04 锁]──[05 锁]──[06 锁]    │ 三任务图标及短标题    │
│ 当前关醒目，可上下滚动章节    │ [挑战 / 解锁 XX金币]  │
│ [全部] [未独立通关] [冲三星] │ 两星可免费解锁的提示  │
```

航线连线只是轻量DOM/SVG装饰，无需另一个渲染框架；当前版本可先用章节分组卡片实现同等信息结构。未开放关卡允许查看要求但不可起飞；点卡片选中，主CTA明确动作。默认滚到推荐关，返回恢复选中和位置。当前三任务为主，历史/救援成绩在详情中可查。

## 03 发射台 / 首次教学

首次第1关用三条短操作说明：“按住喷射→松开滑行→左/右转向”，靠近对应控制区显示。保留已存在的关卡专属机制说明，首次遇到时呈现紧凑简报，可查看详细规则；重复航线不再强制确认已读教程。发射台仍由实际按下推进器起飞。

远征发射台固定短标识：“死亡即结算 · 点火前可保存退出”。不能只放在帮助页。退出未发射状态时明确“已保存”；保存失败不能声称成功。

## 04 飞行 HUD：保留现状（用户已确认）

以dev.25实际界面为准：顶部任务/状态、下降或上升速度/离地高度/燃料、双腿与姿态、小字速度、靠近平台时着陆窗口；底部保留操作建议、左右旋转与推进按钮。原有按钮/倾斜两种模式保持。

之前的横屏HUD重排示意已撤下，不能将其作为实施稿。现有HUD不是本轮视觉重设计范围；只检查安全区、模态触控与转屏等真实问题，再按必要性提出最小修正。没有截取到新的游戏实景，静态线框不冒充现有HUD截图。

## 05 暂停与设置

```text
│ 世界停在原处         ┌ 暂停 · 连续远征 ─────────┐ │
│                      │ [继续航行]              │ │
│                      │ [设置]  [本关目标]      │ │
│                      │ 结束本次远征…           │ │
│                      └─────────────────────────┘ │
```

主线允许重新开始；每日回每日；远征未发射显示“保存退出”，已发射显示“结束并结算”。同一位置的动作名称必须反映真实后果。重新开始主线可快速执行；结束远征须确认。

设置横屏左侧“操作 / 声音与显示 / 数据与关于”导航，右侧内容；竖屏改为顶部分段。选择倾斜后显示授权与校准，按钮模式不常驻大段传感器说明。保留低特效、震动、数据导出与清除；清除使用明确文字确认，返回路径不跳层。新增文本大小属可选UI偏好，不改原存档结构的业务字段。

## 06 主线失败 / 救援

```text
│ 背景保留全程航迹      航行未完成 · 主体碰撞          │
│                      一条最有用建议：先降低下降速度 │
│                      [重试本关]                   │
│                      [观看广告 · 检查点救援]       │
│                      查看撞击详情 / 展开航迹        │
│                      ‹ 返回本关                   │
```

不要先让玩家在“原因”和“结算”之间选择。救援说明保持独立/辅助成绩差异，无检查点时说明回发射台；广告失败返回同一失败页。远征采用独立结算，绝不能复用带“重试本关”的按钮。

## 08 远征停靠 / 整备

```text
│ ‹ 主菜单     连续远征 · 已完成3/30    [记录] [榜单] │
│ 第04关 · 下一航段       │ 燃料124/240  左腿80%右腿92%│
│ 累计 02:18.42          │ 本站补给已计入             │
│ 纯净资格保留           │ [资源整备 ›]               │
│                        │ [继续出航 →]               │
│ 保存退出（未发射）     │ 结束本次远征…              │
```

整备子页一项一行：现值→整备后值、金币价格、不可用原因；主要出航按钮可直接从整备页返回飞行。所有操作调用既有交易接口，自动补给不因进入页面再次发放。首次金币或广告整备的资格确认清楚显示“仍可参加综合榜”。

## 09 远征结算 / 双榜

```text
│ 远征结束 · 主体碰撞       3/30 · 00:58.27           │
│ 说明：已完成3关，当前第4关未完成；累计记录已保存     │
│ [查看综合榜 / 同意提交最佳]   [开始新远征]           │
│ 本机最佳  /  本次统计  /  失败建议                   │
│ ‹ 主菜单                                          │
```

纯净资格仍保留但未满30时写“未完成30关，本次不进入纯净榜”，不能展示“资格保留、完成后可参加”这种已无法兑现的语句。完整纯净30关可分别提交两榜，已提交和新最佳状态分开。

榜单页：[综合远征] [纯净远征] 双标签；行展示“名次 / 名称 / 已完成 / 用时”，本机最佳与在线名次分区；大整数编码不作为主显示。纯净行可省略每行重复30/30，标题保留完整通关条件。刷新在标题旁，加载更多在底部；网络失败不是“无成绩”。

## 10 每日挑战

首页一层可达。首屏只放当天日期、航线、三任务摘要、本机最佳、开始；在线参与/已提交状态短句常驻，规则/隐私长文展开。每日榜仍调用真实平台接口，不把本机模拟榜升格为在线榜。技术复核和回放导出移到高级工具，保留能力而非删除。
