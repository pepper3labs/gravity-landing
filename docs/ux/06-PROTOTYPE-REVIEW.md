## 打开与操作

使用已恢复的本机预览：[打开原型](http://127.0.0.1:10453/docs/ux/prototype.html)。源文件为 prototype.html、prototype.css、prototype.js。刷新或“重置原型”清除示例状态；“保存退出”仅在本页内演示，关闭页面不会保存。

建议走三条路径：

1. 开始航行 → 第1关说明 → 发射台占位 → 模拟成功 → 奖励自动到账 → 继续下一关。
2. 连续远征 → 开始 → 暂停 → 保存退出 → 继续远征 → 资源整备 → 取消/确认 → 起飞 → 模拟失败 → 直接结算 → 综合榜/纯净榜切换。
3. 每日挑战 → 参与榜单选择 → 出发 → 暂停 → 设置 → 完成设置 → 继续。

所有飞行页面只是流程占位，不显示新HUD，不请求传感器；真实游戏链接保留原场景和HUD。示例金币、燃料、成绩均非经济/物理计算，不能用于验证30关、排名编码或广告奖励。前两关可演示，后续选关置灰并明确标注“原型未展开”，不代表更改正式解锁规则。
