# 分阶段实施与验收计划

## 2026-10-23 最新确认：手机竖屏优先

以手机竖屏触控为首发设计与验收基准（390×844，覆盖360×640、430×932），桌面兼容。横屏仅作兼容检查，不再作为主设计方向或首发P0门槛。下文历史横屏布局、双列示意及横屏任务要求均以本条为准。

菜单遵循手机操作：内容纵向滚动，每页一个明确主动作，主要继续/出发/重试位于内容下方的拇指可达区域；长页使用不遮挡内容的底部操作区，保留系统底部安全距离。返回固定在左上且逐层返回，危险动作与继续分开，广告作为次级可选操作。目标至少48×48 CSS像素，不依赖悬停、精细点按或横向拖动。现有飞行HUD、双指按钮与飞行镜头保持；不能把菜单尺寸规范套用成HUD改版。


## 2026-10-23 用户评审更新：保留当前飞行 HUD

用户明确认可现有飞行HUD。后续保留dev.25的遥测项目、信息层级、位置、视觉样式、操作按钮及提示方式，不实施本轮提出的HUD重排、精简或新布局。默认不调整飞行镜头。菜单、选关、远征、暂停、结算与设置继续按方案评审。

横屏适配和四边安全区仍须验证，但不能以此擅自替换已认可的HUD；若实测发现必须调整HUD或镜头才能适配的冲突，单独呈现问题和最小改动方案。触控释放、模态输入隔离、传感器异常及返回路径可以继续审查；具体实现仍在后续阶段。


本轮停在审查与方案交付。下面是后续重构顺序，不表示已经实现；版本不提升、不打包、不上传、不调整平台方向。

## 真人任务与量化目标

建议至少6名不同玩家，其中3名从未玩过、3名熟练玩家；每名至少完成横屏触控任务，其中至少2名体验倾斜。样本用于发现问题，不代表统计意义上的上线转化预测。

|任务|起点与操作|通过条件|
|---|---|---|
|T01 新手启程|全新存档首页→找到第1关→点火→停止推力|至少5/6无需口头指导找到入口；首轮阅读/进入控制目标60秒内；新手不能被送第2关；不以立即通关作为UX条件|
|T02 下一关|主线通关，已有下一关解锁且机制已见|无需找“结算”入口，1次有意点击进入下一发射台；新机制最多另1次|
|T03 失败分流|主线失败→重试；另一次选择救援|重试1次，救援入口1次可达；玩家能解释二者区别；救援真实SDK完成/取消各一次|
|T04 金币/解锁|一星通关、余额够/不足各一份测试存档|能说明已到账数量和解锁方式；0误扣、0重复领奖；两星免费路径可发现|
|T05 双指飞行|同时左/右转与喷射，交替松开，滑出按钮，系统取消|20组动作无粘键/误触；松开全部喷射触点后下一输入处理帧推力停止；惯性仍保留|
|T06 模态边界|按住→暂停/设置→松开→返回；Esc逐层返回|世界不在菜单下继续模拟；恢复后不自动点火；来源与焦点正确|
|T07 远征未发射保存|整备/发射台未点火退出，关闭再打开|资源/关数/累计统计相同，无新增补给；明确看到继续入口|
|T08 远征死亡与结束|飞行死亡、暂停取消结束、确认结束、飞行强关|死亡无重试；取消不结束；确认不可恢复；异常退出符合现行仅本机结算；0误结束|
|T09 整备资格|纯净远征首次金币/广告整备，取消与确认各一次|100%测试者能说出失去纯净资格、仍可综合；取消不扣币、不提前播放广告|
|T10 排行榜|部分已结算→综合；纯净完整30关→两榜|显示真实完成数/用时；本机/在线区分；提交与失败/重复/空榜可辨；完整30关资格不得用假数据冒充平台通过|
|T11 每日与设置|首页进入每日，选择参与；查设置后返回|无需进入主线找每日；返回正确；原同意后自动提交行为不变；零点另做跨日实测|
|T12 旋转/倾斜|按钮与倾斜中横竖转屏、传感器停止、恢复|暂停/提示/校准符合规范，不能无提示继续失控；回退按钮模式可用|

测试记录每项成功/失败、耗时、点按次数、走错页面次数、误触次数及玩家原话。场景内真实操作录像须先征得试玩者同意，默认本地留存，不增加线上遥测。基础菜单任务目标≥90%独立完成（小样本同时报实际人数）；不可逆误操作和奖励错误容忍度为0。长篇规则阅读不是测验：通过让玩家执行任务验证理解。
