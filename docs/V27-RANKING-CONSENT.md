## 玩家行为

- 首次点击每日开始、远征新建或旧远征继续出航时，尚未选择的模式显示原生弹窗：参与排行 / 仅本机记录 / 返回。Esc或返回不开始、不授权。
- 明确说明关联当前TapTap账号、展示昵称/排名/成绩，只发送分数、不上传飞行回放。选择保存本机，旧每日yes/no不变；远征独立授权。
- 拒绝仍可正常游玩，下次开始不再询问；设置 → 排行榜参与设置分别修改每日/远征。设置启用仅影响后续结算，历史未提交最佳可到榜单手动提交。
- 每日沿用通关复核、北京零点规则。远征在完成/死亡/主动结束且结算保存后，自动上传本次形成的合格个人最佳。无整备完整30关可进入两榜，部分成绩/整备仅综合，零进度/无效/进行中不提交。
- 双榜请求串行且独立确认；重复回调不重复发送；迟到结果不能确认另一次新最佳。失败保留本机最佳并提供手动重试，不在后台循环重试。
- 关闭阻止后续及尚未发出的排队请求，不撤回已发请求或已上传成绩。直接关闭客户端可能使请求来不及完成，重新打开后可手动补交；不承诺离线或后台继续提交。
