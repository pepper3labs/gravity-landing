# dev.16 三任务星级

用户2026-10-17确认实施，替代原“满足整组条件才给二星/三星”。游戏共30关/90星，物理、关卡ID、操控、救援策略和轨迹不变。

## 规则与展示

1. 成功着陆：抵达目标平台，包括合法单腿抢救。
2. 双腿完整：成功着陆时两条腿都未断；允许受损，没有额外耐久、主体或速度门槛。
3. 本关专项：成功着陆并完成该关一个指标，选择余油、触地合速度或用时。

两颗附加星互不依赖；失败全部零星/零金币。结算按任务顺序展示★☆★等真实位置，逐行标注已获得/未获得、目标、实际值和差距。起飞前与暂停可查看同一任务定义。复玩已读教学的关卡展示简短目标，不再直接跳过目标页。练习仍显示参考星级但不保存。

配置为src/star-tasks.ts的稳定ID映射；数值取该关旧scoring.three对应的单项阈值，未改变物理配置或旧关卡指纹：

| 专项 | 关卡编号 |
|---|---|
| 余油 | 1、3、5、6、8、10、11、12、13、16、19、24、26、27、30 |
| 触地合速度 | 2、7、9、14、17、18、20、21、22、23、25、28、29 |
| 用时 | 4、15 |

黑洞终局要求余油至少20%，无需计时赶路。触地合速度使用现有touchdown法向与横向速度的合量，不使用停稳后的零速度。先比较原始数值，再定向显示两位小数，避免略超限却显示相同数值而不解释。

## 兼容与奖励

- src/scoring.ts继续作为旧评分器，不修改既存严格回放；实时游戏使用scoreTaskFlight，UI与发奖使用同一个tasks结果。
- 分数继续为每星1000分加原有燃料/用时/完整度分；金币继续baseCoins+(stars-1)*25。此次规则变化允许原本因某一整组条件被降星的航行获得更多星，不追溯改旧分或发金币。
- CampaignProgress的normal/assisted继续保留累计最佳及旧解锁；新增starTasks:{rules:'tasks-v1',normal,assisted}独立统计新规则。界面区分历史累计与三任务成绩，新纪录只比较同规则/同辅助轨。旧三星不充当新任务完成，重玩推荐读取三任务三星。
- daily-v2沿用日期与固定关卡池，但挑战ID和任务规则指纹独立。daily-v1摘要/档案仍能加载和严格复核；同一天的新旧分不混排。既有存储容量限制继续生效；未接入真实榜单。
