## 玩家流程

- 首页 → 排行榜 → 综合远征 / 纯净远征 / 每日挑战；左上角房屋图标返回首页。
- 每日结算 → 查看排名 → 每日榜。远征死亡或主动结束 → 查看排名 → 综合榜；完整纯净30关结算 → 纯净榜。
- 远征进行中菜单及每日说明不再重复提供榜单入口。进入或切换榜不提交成绩。
- 每日沿用首次同意后自动提交；远征保留明确同意提交个人最佳，两榜相互独立。
- 本机纪录、我的线上排名与在线列表分别显示。综合成绩还原为关数及有效飞行时间，不直接显示编码大整数。空榜、不可用、加载失败各有独立提示。

所有展示复用原生DOM/现有按钮，无新增依赖。三标签与列表操作至少48px；保持竖屏、长页滚动与当前飞行HUD。当前运行会话记住最近标签，不写入存档。

## 平台边界

经核对官方接口，使用[loadLeaderboardScores](https://developer.taptap.cn/minigameapidoc/dev/api/open-api/leaderboard/LeaderboardManager.loadLeaderboardScores/)读取public榜单，20条分页；用[loadCurrentPlayerLeaderboardScore](https://developer.taptap.cn/minigameapidoc/dev/api/open-api/leaderboard/LeaderboardManager.loadCurrentPlayerLeaderboardScore/)读取当前账号排名。游戏UI没有打开平台榜单面板的调用；底层旧open适配保留兼容测试。

每日请求北京时间当日的秒级周期token（零点至23:59:59），响应周期必须一致，个人排名周期也必须匹配。分页及请求结束后再次检查日期；跨零点要求刷新，不展示旧周期成绩。真实平台周期回执仍须验证，不能把模拟测试当作兼容性确认。

单次读取15秒超时，离开页面/切换标签后的响应不覆盖当前界面。个人排名失败不隐藏已成功读取的列表。昵称仅作为文本显示。普通浏览器缺少平台接口时明确提示不可读取，不注入假在线数据。原排行榜ID、编码、SDK提交规则与玩家授权不变。
