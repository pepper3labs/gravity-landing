# 本地试玩诊断交付

日期：2026-10-14。版本仍为 v0.6.0；本批次不修改物理、八关配置、救援奖励、战役进度或广告策略。

## 使用

在「选择航线」底部点击「试玩记录 · 查看与导出」，然后选择「导出试玩记录」。JSON 只写入本地下载目录，由玩家自行决定是否分享。

- 独立键 `gravity-playtest`，schema version=1；最多保存最近 200 次尝试，与旧存档、金币互不覆盖。
- 记录关卡、开始/结束时刻、模拟飞行秒数、余油、失败原因、救援及辅助状态、重试/离开方式。
- 失败后救援属于同次尝试：保留失败历史，继续累计航行用时，最终成功归为辅助成绩。
- 进行中重试/回菜单记为放弃；关闭/刷新记为中断；已经失败或成功后离开保留终局状态。浏览器返回缓存恢复同次记录。
- 本次窗口内统计每关独立/辅助成功、失败事件、放弃、中断、重试、首次独立成功前尝试数和累计飞行秒数。尚无独立成功时字段为 null；累计秒数不包含停泊等待、暂停、广告或后台时间。
- 着陆练习、开发指定关卡和 QA 排除。普通手动入口本身不能证明是人操作，因此导出明确注明不能作为真人/实机验收证书。
- 只在生命周期节点写入，不逐帧访问存储；不发网络请求，不采集账号、设备指纹或定位。
- 损坏/未知版本数据保留原值，当前会话仍可记录和导出；存储失败提示及时导出。

类型检查（包含在生产构建中）、全量 82/82 测试、十四关 14/14 输入驱动验证通过。旧八关严格基线仍通过，物理结果 JSON 没有内容差异。构建保留既有 Phaser 大包提示。

证据：`evidence/diagnostics-tests.txt`、`evidence/diagnostics-build.txt`、`evidence/diagnostics-routes.txt`、`evidence/diagnostics-browser-export.json`。导出样本是 AI 浏览器操作产生的测试数据：两次放弃、一次重试、零通关，绝不能作为真实玩家难度指标。初次沙箱内预览无法访问，重新以批准的本机 loopback 服务启动后检查通过；未改变防火墙或对外发布。
