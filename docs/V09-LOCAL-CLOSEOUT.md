## 可重复验收

在项目根目录运行 `npm run verify:v09`。顺序执行类型检查、全量测试、23关永久回放、附加三星回放、既有每日回放、普通/H5构建及两种产物审计。失败立即停止后续构建；每次日志和摘要保存在 `artifacts/v09-validation/<时间>/`。不重录旧回放，不覆盖历史关卡结果，不上传或发布。

发布门槛单独记录在 `release-gates.txt`。本地工程通过可以返回成功，同时发布状态仍为 `ready:false`；不能以命令退出0声称可上线。配置解析出错属于验收失败。

本轮149/149测试、23/23主档、独立三星档、每日档复核和两种构建通过，见 `evidence/v09-local-*`。浏览器候选10466验证管理入口、空/错误确认文字禁用、正确文字启用、取消返回，以及空存档备份真实下载。没有点击永久删除；删除范围及存储失败由独立内存存储测试验证。浏览器检查没有捕获到error日志；这不是完整P0/P1审计或真人验收。
