# v0.6 工程收尾

2026-10-14。基于 e056c7b。用户要求完成 v0.6 并进入 v0.7；本记录只确认工程功能和自动验证，不将尚缺的人测门槛改为通过。

本批补齐本地性能摘要：最近 20 次正常入口航行、每次默认/低特效两组固定桶，记录样本数、总帧间隔、最大值、均值及间隔换算帧率。取单调时钟的实际帧间隔，不使用截断后的物理 dt。只在可见、非暂停/广告/设置且飞行状态下采样，停泊/恢复首帧、模式切换首帧、练习和 QA 排除。无逐帧存储、设备探测或上传；刷新清空，手动导出附在 performanceSession 字段。不是 GPU 耗时、平均手机帧率或真人凭证。

验证：103/103 测试、类型检查/生产构建、14/14 历史磁盘回放通过；原八关严格基线通过。日志 evidence/v06-close-*.txt。生产 10458 正常入口实际起飞、暂停、回菜单、导出通过；evidence/v06-performance-browser.json 为 AI 操作样本，1430 个间隔、约 8.7 秒，不能据此推断实机性能。截图 performance-session.jpg。

v0.6 工程范围：十四关、环境与航迹、旧档迁移、正常/辅助成绩隔离、模拟广告异常恢复、基础设置、试玩与性能导出、永久回放均已实现。无物理/关卡/评分变化，既有 Phaser 大包提示仍在。

未退出门槛：新六关真人独立通关、手机双指/后台/音频/震动/性能和完整人工缺陷审计。发布仍未批准，真实平台集成仍未实施。以 v0.6-engineering-baseline 标签保存本批工程回退点；该名称不表示真人稳定版。

按用户授权进入 v0.7 开发，首批实现重玩目标筛选与独立成绩目标，后续再开展 15–17 关内容设计与逐关回放验证。v0.7 开发不抹去 v0.6 待验收项。
