# v0.4 可玩性与视觉体验评估

## v0.3 的具体问题
基于源代码检查、原版浏览器画面和操作记录，而非玩家统计。

| 观察 | 对新玩家的影响 | v0.4 的处理 |
| --- | --- | --- |
| 旋转释放后仅 0.7 的角阻尼，没有喷口音效 | 持续自转，很难知道何时松手 | 固定步中增加松手角阻尼 2.8、角速度上限 1.65；保留朝向与惯性，增加姿态喷口和短促声音 |
| 喷焰是每帧随机的单色三角形 | 点火只有开关感，推力与重量不明显 | 分层喷焰、推力亮度渐变、尾焰粒子、发动机合成低频声；实际主推力仍为 72 |
| 镜头每帧固定插值 0.06、固定飞行缩放 | 跟随手感随帧率变化，看不清速度和着陆冲击 | 按时间指数平滑、速度前瞻、高空拉远、独立短时冲击震动、画面安全区域内的目标箭头 |
| 支架压缩通常不足 1 个世界单位，没有接触事件 | 玩家无法辨认缓冲、受损和断裂 | 物理事件驱动阻尼压缩回弹、触地尘埃、低频碰撞音、断裂碎片与火花 |
| 星球和飞船都是单层占位形状 | 缺少材质、比例和统一风格 | 本地生成星球纹理、陨坑、明暗面、大气边缘；装甲、驾驶舱、发动机喷口和独立支架 |
| 只展示总速度和一句通用提示 | 不清楚何时制动、向哪个方向制动 | 分解下降、横移、姿态；标明惯性方向；动态四阶段引导和制动距离预警 |
| 无开始界面、无音效、所有通关只有同一种文案 | 缺乏目标感和完成感 | 任务简报、开始/暂停/复盘界面、合成音效、S/B/R 三类着陆结果 |
| 断一条腿后虽然还能飞，但不能完成任务 | 补救缺少实际意义 | 允许单腿损坏后的真实主体低速接触迫降，稳定 1.8 秒计为抢救成功 |

## 首次游玩的目标体验
- 任务简报明确三个动作：点火爬升、短喷转向、减速着陆。
- 起飞前稳定停泊，无操作不会坠毁；右手按住推进，左手可同时旋转。
- 起飞后发动机声和喷焰迅速建立，镜头放大并保留速度前瞻，琥珀线显示惯性方向。
- 松开旋转后自转逐渐衰减；这不是自动回正，仍需要玩家决定机头方向。
- 下降危险时以颜色、文字和声音同时提示“立即制动”，不只报一个总速度。
- 失败显示主体冲击、下降速度、姿态偏差和下一次应如何操作。
- 提供同一关卡的“先练着陆”入口，跳过转移航段，便于在前 30 秒体验制动和触地。练习不计金币。

## 物理边界与结果
原有星球、关卡、重力求和、固定 1/120 秒、支架弹簧阻尼、独立耐久和主体致命阈值保留。现有九项测试未修改。
增加的旋转辅助是固定步内的明确物理参数，不是视觉补偿。视觉压缩、粒子、震动和声音只读取事件。
事件队列有 64 条上限；消费或不消费事件得到相同物理状态。

普通着陆仍要求双支架接触、下降 <9m/s、横移 <7m/s、姿态误差 <0.2rad、角速度 <0.25rad/s，松开推进稳定 1.1 秒。
单腿迫降必须有真实主体接触目标平台，下降/横移均 <4m/s、姿态误差 <0.85rad、角速度 <0.35rad/s，稳定 1.8 秒。主体严重撞击仍立即失败。不会给断腿添加支撑。

- 完美着陆：支架耐久均 ≥95%，主体冲击 <4m/s，支架峰值冲击 <18m/s，无救援。
- 受损着陆：满足普通着陆条件，但未达到完美标准。
- 抢救成功：单腿迫降、断腿后脱险再着陆，或安全检查点救援后完成任务。
- 对应任务奖励 150 / 100 / 120 金币；练习与开发验证场景不计金币。

## 性能与兼容策略
纹理启动时生成一次，复用 CanvasTexture；无需图片、字体或音频网络请求。无后处理、实时阴影或全屏模糊。
星点 110 个；活动粒子最多 150；合成音效并发最多 16；HUD 每 100ms 刷新；物理保持 120Hz。
Phaser 独立 vendor chunk 便于缓存。主包体积仍是首次加载的主要成本，未为消除警告而伪造拆分或隐藏体积。
支持 prefers-reduced-motion：关闭震动和闪光，减少持续尾焰粒子。原生触感在支持 Vibration API 时启用。
音频从玩家第一次点击后解锁；静音可用 M 或顶部图标。窗口失焦/隐藏自动暂停并清理输入。
触控使用独立 pointerId 集合，处理 pointerup、pointercancel、lostpointercapture，避免双指松手互相干扰。

## 验证记录
- 保留并通过原九项回归：十分钟停泊、主动起飞、单腿补救、断腿移除碰撞、独立主体撞毁、稳定目标着陆、支架高速断裂、安全救援和完整航线。
- 新增九项回归：多指取消/清理、松手角阻尼、三类结算、单腿真实迫降、失衡倾倒、失败复盘、危险下降、事件不影响物理、镜头平滑帧率一致性。
- 390×844 与 360×640 浏览器视口检查了开始、游戏和失败面板；起飞、旋转和暂停进行交互验证。
- 浏览器未报告应用脚本错误。

## 仍需实机验证
浏览器响应式检查不等于手机硬件测试。尚未实测 Android/iOS 的持续帧率、音效听感、触控延迟与震动支持。
当前是单关垂直切片，尚无正式 TapTap SDK、设备性能分档、长局疲劳测试或多人新手可用性研究。
平台和地表采用离散点接触，当前速度范围有回归覆盖；未来若加入高速撞击或极小天体，需要重新评估连续碰撞。
