# v0.8 首批：本地每日挑战

2026-10-15，版本0.8.0-dev.1，基于二十关提交16f11e6。用户已授权向v0.8推进；常规设计自主决定，真人意见后补。

## 可试玩内容

选关页上方进入“每日挑战 · 本机纪录”。固定七条已经验证的航线轮换：减速训练、低重力飞行、静态小行星穿越、动态小行星避障、逆向绕行、交错巡游、大气边界。显式稳定ID列表不随战役扩关自动变化。

以UTC日期为准，北京时间08:00切换。开局固定日期和航线；跨日仍可完成旧局，重新出发或在过期简报点开始会显示当日挑战。障碍时钟沿用物理模拟时间，停泊和暂停不会推进。

挑战可进入战役尚未解锁的航线，但不写战役解锁、教学、星数或金币。可免费重试，不显示广告救援、补给或翻倍按钮。原战役广告策略完全不变。每日挑战暂不混入战役试玩统计和性能摘要。

完整输入在内存有界记录（最多57600步/8分钟），结算重新从发射台执行，检查终局再计算成绩；拒绝练习、救援、非法输入、截断、终局填充、超长和日期/规则不匹配。暂停帧、无操作停泊和终局额外帧不记录。超出上限仍可继续游玩，但不计每日纪录。

本机最佳按分数、用时、余油排序；独立 gravity-daily/version1 存储最近30个挑战日最佳摘要。损坏/未来版本保留原值并临时工作，写入失败不阻断游戏。存储中不保存账号或联网数据。
