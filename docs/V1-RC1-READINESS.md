## 上线前尚未关闭的事项

1. **用户操作**：在后台阅读/签署协议，确认适用资质和主体；提供正式运营名称及公开联系渠道，用于正式隐私说明。当前 `about-data.html` 明确只是测试数据说明，不能当作完成的正式隐私政策。
2. **商店资料**：简介、开发者的话、推荐语、宣传图、截图、实机视频、自定义图标；核对素材来源/授权和AI披露。已有第三方代码声明不等于全部素材审核完成。
3. **真人验收**：扫码本候选验证一屏教程/结算；Android/iOS安全区、双指、后台/音频、倾斜失联恢复、黑洞场景性能；普通玩家在资源继承条件下完成30关远征并记录结果。
4. **真实服务最终核对**：已有用户广告和每日自动提交成功反馈、远征综合榜可见成绩反馈及首次整备确认反馈，予以保留，不要求重新否认既有成功。仍缺本候选的取消/失败边界记录、三榜正式可见范围/非白名单账号、每日北京时间零点、完整纯净远征双榜回执。旧测试成绩处理需用户决定，不能自动删除。
5. **发布动作**：验收完成后锁定最终包，明确批准主包绑定和提审；通过审核后再批准公开发布。当前无需新建服务器。
