# 1.0 前功能扩展：金币经济与连续远征

2026-10-23 更新死亡结算规则；2026-10-22 用户最终授权，覆盖旧 v0.6/五关远征方案。只交付自测包，不提审、不公开发布。

## 最终范围
- 主线30关：前两关开放，完成第2关开第3关；其后两星免费解锁、一星购买；已解锁不回锁。零余额首次一星+一次双倍广告或1–2次重复通关足够解锁。
- 统一持久化钱包：首次星级差额、重复奖励、广告追加、购买解锁、远征整备一致提交；旧余额保留，历史星级为已领取基线，不补发。
- 远征独立30关顺序，不要求主线解锁、不自由选关、不发金币、不写主线成绩。
- 资源真实继承；固定补给仅一次；加油、双腿维修/重建、全面整备及可选广告；死亡立即结算，不允许重试，累计时间/燃料/损伤保留。
- 只有未发射（整备站或发射台未点火）可以保存退出并继续；飞行中暂停可以恢复，但退出即结束本次远征。异常中断保守补计并结算，仅本机记录；旧版等待重试存档同样结算且不可上榜。损坏原文不得覆盖，可新开临时远征。
- 完整完成、死亡或主动结束时结算；已结算不可继续。纯净榜仅30/30且无金币/广告整备，时间升序；综合榜按完成关数降序、同进度时间升序；纯净完整成绩可入两榜，分别保留最佳。
- 每日挑战、原物理、三任务、旧成绩、触摸与倾斜保持隔离。

## 实施顺序
1. 平台能力核对、最终规则与持久化设计。
2. 经济核心、30关参数、迁移与解锁。
3. 远征状态机、逐步统计、资源快照和真实30关回放。
4. 双榜适配、真实回执和缺配置提示。
5. 移动端界面、全回归、审计和自测上传。

## 验收边界
自动驾驶与消耗模型只证明设定假设下可行，不等同普通玩家真人验收。没有服务器，不能承诺防本地改档。新榜需真实后台ID/配置，缺少时明确未接通，不使用虚假榜单。平台原生数值榜是否支持丰富列/附加数据以官方接口证据为准。

## 已实施的具体决策
- 首批即完整30关，远征不发金币、不自动解锁主线。纯净只完整30关；综合可部分已结算；未结算不提交。
- 统一240容量、各站补给参见BALANCE.md。未发射可保存，首次点火前写入出航状态，死亡/飞行中退出结束本次远征；帧前预写上界/帧后准确日志，异常帧中断保守补计后结算并取消资格。损坏原文保留，尽量用备份恢复为临时不可上榜状态。
- 钱包/解锁/主线成绩/远征整备采用单键原子提交，修订号检查阻止过期标签页写入，备份不作为恶意回滚防御。旧gravity-campaign及gravity-coins原文仍保留，新状态权威键gravity-economy-v1。
- 单关首次差额和重复奖励互斥，普通/救援共享领取星级；广告只追加本次金额。旧星级为领取基线，损坏缺失星级的已完成关保守按三星已领取，不补发。
- TapTap整数单分数、无附加字段；纯净步数升序，综合可逆编码降序；游戏内真实分页行显示关数与时间。平台配置与限制见PLATFORM.md。
