# 平台接入与验收：远征双榜

核对日期：2026-10-22。用户创建并提供两张榜，官方list_leaderboards读回名称、ID和“不重置”；排序、最佳策略、范围和白名单为按设置问题提供ID的用户配置，仍需手机验证。

|榜|客户端ID|后台ID|排序|平台单位|
|---|---|---:|---|---|
|纯净远征|<leaderboard-id>|<board-db-id>|整数升序、保留最佳|步数|
|综合远征|<leaderboard-id>|<board-db-id>|整数降序、保留最佳|分|

纯净值=累计有效物理步数，每120步=1秒；仅有效、已结算、纯净且30/30接受。综合值=完成关数×50000001+(50000000-累计步数)，可逆解码，所有30关成绩优先于29关及更低关数。上限50000000步约115.7小时，仅限制在线编码，超过仍可继续本地游玩。相同关数和相同步数本机保留较早最佳；平台最终同分名次按平台规则，不伪造本地排序。累计燃料/损伤用于本机统计，不作为榜单额外排序（遵循用户最终简化规则）。

## 官方能力证据
- https://developer.taptap.cn/minigameapidoc/dev/api/open-api/leaderboard/LeaderboardManager.submitScores/ ：每次最多5项，整数score，leaderboardId；无自定义附加数据。回执含各榜rawScore和平台身份；只接受匹配且不差于提交成绩的有效回执。
- https://developer.taptap.cn/minigameapidoc/dev/api/open-api/leaderboard/LeaderboardManager.loadLeaderboardScores/ ：真实分页scores含rank、score、user.name，支持continuationToken。游戏内读取真实行并解码展示完成关数/时间；不生成虚构玩家，页面错误明确提示。
- 原生界面只能看到单位为步数/分的编码；本次使用游戏内榜单显示可读关数和时间。未申请好友权限、未下载头像、未上报完整回放。

身份由当前TapTap宿主账号关联。玩家主动同意提交各榜本机最佳，成功回执持久标记；重复点击受请求锁/已提交标记约束。换账号时不自动补传，不保证跨账号本机最佳归属；界面有归属提示。没有自建服务器或可信回放服务，不能防止恶意改本地存档；仅提供合法流程的单次结算、字段验证、范围检查、恢复标记与幂等保护。
