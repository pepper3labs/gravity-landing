## 推荐实际操作顺序

1. 用生产版本从主菜单开始；新玩家先体验前两关。记录是否读懂推进/旋转/惯性，是否需要旁人提示。教学建议不等于通关记录。
2. 用已自然解锁的进度测试第 9–14 关。若采用开发指定关卡，明确标为开发场景；它不能证明生产解锁或存档流程通过。自动路线、从目标上空练习、QA 初始状态不能记为完整手动通关。
3. 每次失败先记原因和可理解程度，再重试；救援发生在同次尝试内，记次数并将最终成绩标为辅助。不以救援成功替代独立通关证据。
4. 按下表检查触摸、设置、后台、结算与持久化。损坏/迁移试验只用备份副本和隔离测试环境。
5. 在关卡选择底部打开“试玩记录 · 查看与导出”，保存 JSON 到本地，填写文件位置；分享由操作者决定。最近 200 次窗口可能不完整，导出不自动证明真人身份，飞行秒数不含暂停/等待时间。
