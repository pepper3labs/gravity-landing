# 模拟激励广告恢复

日期：2026-10-14；基于 1f5e429，版本仍为 v0.6.0。

## 行为

- 模拟展示可主动取消；取消或异常后回到完整结算页，保留说明与免费重试入口。
- 每个请求有独立标识；取消、重开、切关、返回菜单或 pagehide 会使旧请求失效。迟到结果不发奖、不覆盖新请求状态。
- 同时只展示一次；通关奖励仍受原有每局一次限制。奖励额度、救援次数策略、辅助成绩隔离和物理参数未修改。
- 默认仍为 1.8 秒成功模拟。取消只使结果失效，模拟计时器可能仍运行；未来真实 SDK 需另行适配关闭事件，没有接入真实广告。

## 开发复现

开发服务器打开 `?qa=ad&ad=failed`、`?qa=ad&ad=cancelled` 或 `?qa=ad&ad=completed`，开始后由正式物理求解器产生失败，在结算中选择模拟救援。此入口为练习验证，不保存战役成绩、金币、教学进度或试玩诊断；生产构建禁用。
