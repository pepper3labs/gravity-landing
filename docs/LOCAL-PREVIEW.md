# 本机浏览器预览

## 固定入口

在项目根目录的普通本机终端运行 `npm run preview:local`，保持该服务终端运行，然后打开 http://127.0.0.1:10453/ 。仅绑定本机回环地址，不对局域网开放；不是手机真机联调地址。首屏版本当前为dev.25。

Codex的受限执行环境会限制网络。由代理启动时，使用允许本机网络的执行环境运行同一命令；这不要求用户以管理员身份运行浏览器，也不需要关闭防火墙、修改代理或开放公网。启动成功日志不能单独视为连通成功，必须确认HTTP响应和浏览器页面。

服务端口固定且启用strictPort：冲突时报错，不自动跳到另一个地址。已有健康服务可直接使用；已有进程异常时先核对其命令行确属本项目，再结束旧服务。不要不断更换端口累积进程。历史10475–10478地址已停用。

## 故障检查顺序

1. 看服务是否运行、地址/端口是否与浏览器一致。
2. 在可联网的本机执行环境检查TCP与HTTP；连接超时、HTTP错误、页面脚本错误分开诊断。
3. 用浏览器确认实际标题、场景和按钮交互。TCP200不能代替渲染验证。
4. 端口占用时核对具体进程，不全局结束node进程、不降低系统安全设置。
5. 通过新地址打开时，本机存档按浏览器origin隔离。旧端口或不同IP的存档不会自动出现在新地址，不能误判为数据被删除；原数据未清除。
