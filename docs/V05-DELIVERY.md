# v0.5 交付与验收记录

> 此文记录原版短航线。当前 v0.5.1 已按实玩反馈延长航线、降低灰月重力并重设远距伴星；最新参数及结果见 [v0.5.1 调整记录](V051-FAR-SIDE.md)。`v05-route-results.json` 已更新为最新航线。

## 从 v0.4 延续的体验

修改前通过全部 18 项原测试，保存 Git 提交 `80e62f4`，标签 `v0.4-stable`。原测试文件未修改。
原项目限制主要是单一硬编码关卡、固定首星球遥测/全景、缺乏成绩与关卡进度循环。v0.5 没有重写物理、音效、触控或美术，重点补齐六关连续游玩。

## 六关配置

所有关卡使用 GL–01 双支架飞船、停泊初始状态，主体致命冲击始终 14 m/s。角度相对目标平台法线；角速度 <0.25 rad/s 才能正常稳定着陆。速度界限为严格小于。

缓冲倍率同时乘原弹簧与阻尼，强度倍率乘安全/断裂冲击阈值；损伤倍率均为 1。初始燃料是物理储量，HUD 显示相对容量的百分比。

单腿迫降各关均允许：必须只有一条断腿、真实主体接触目标，法向与横移均 <4 m/s、姿态 <0.85 rad、角速度 <0.35 rad/s，松开推进后稳定 1.8s。没有隐形替代支撑。

- 第一关：宽台、充足燃料和强化支架，让玩家练习起飞、朝向、短喷和轻触。
- 第二关：目标角度从 -1.18 扩展至 -0.88 rad，航程增加，突出提前反向制动。
- 第三关：低重力但推力不变，较小喷射就会明显改变航迹。
- 第四关：两颗星球始终叠加引力，从 (0,720) 的起航星飞往 (760,630) 的远岸，目标角度 -1.45 rad。HUD 接近时采用目标平台法线，不沿用第一颗星球。
- 第五关：58 m 窄台、标准强度双腿，收紧横移与姿态条件。
- 第六关：目标左缘沿切向 -30 m 的检修桩，高 25 m、圆帽半径 10 m，有真实胶囊形碰撞。中央安全航线不强制损坏；偏左落下可能先撞断左腿。允许完整着陆与单腿迫降。

每个坐标、朝向、目标、教程及评分阈值可在 `src/levels.ts` 查看和调整，主流程没有按关卡编号分支。

双星驾驶器首次尝试失败，原因是低空强制回正忽略了另一星球的侧向引力。修正的是验证驾驶器，玩家操控与物理参数未变。当前航线首次触地偏差约 17.6°，缓冲后回到稳定窗口，合法通关但未达到三星的 12° 接触精度要求；没有为了报告三星而放宽规则。

另有两项独立局部测试（不能等同于完整受损航线）：
1. 第六关高度 58、切向偏移 -18、下降 43 m/s，真实检修桩只撞断左腿；随后持续推进可重新抬升至平台上方超过 100 m，右腿 100%，主体冲击 0。
2. 第六关单腿低速迫降，真实主体支撑并稳定 1.8s 后通关，断腿接触点持续关闭，最高不超过二星。

## 评分与存档

- 一星保证所有合法通关，不因耗时或燃料少而剥夺通关/解锁。
- 二星：余油至少 8%，用时不超过三星上限的两倍，尚完整支架健康 ≥35%，主体完整度 ≥60%，接触速度和角度不超过三星的两倍。
- 三星：双腿完整且各 ≥90%，主体 ≥90%，并同时满足各关燃料、用时、接触速度与角度要求。

主体完整度为 `max(0,100−70×本次最大主体冲击/致命冲击阈值)` 的成绩指标，不新增隐藏生命值或更改致命条件。接触速度/姿态在碰撞响应前采样，不使用结算时清零后的速度。离开平台超过 0.35s 后再次接触视为新的触地。

分数综合星级、余油、耗时、主体及双腿健康；金币 100 / 125 / 150，模拟广告再给一次相同金额。
浏览器 `gravity-campaign` 保存 version=1、最高解锁、完成/教学状态、每关独立成绩与辅助成绩；各自保存最高星级/分数、最短时间、最大剩余燃料。这些最佳项可以来自不同次通关，不伪装成同一次飞行。
未知未来版本或损坏 JSON 保留原文本，本次采用临时进度并提示；合法版本中的非法成绩被丢弃。解锁按已完成的连续关卡重建，不信任单独被改写的最高关卡数字。存储不可用时仍可在本次页面内游玩。旧版金币键保持不变。

## 相比基线的物理差异

**未改：** 固定步 1/120、推力 72、旋转加速度 3.8、角阻尼 0.7/2.8、角速度上限 1.65、耗油 2.8/0.18、质量 1、惯量 210、飞船/支架几何、主体四个采样点、原接触冲量公式、独立断腿行为。`CONFIG` 和默认 `LEVEL` 保留。

**新增或修复：**
- 关卡覆盖重力、初始燃料、支架倍率、着陆阈值；普通未配置实例行为仍按基线。
- 将原引力求和提取为共用函数，遥测按最近地表与目标平台分别计算。
- 检修桩实体碰撞，渲染与物理共用位置/形状配置。
- 燃料为零但已满足目标稳定条件时，继续完成着陆确认；胜利后立即结束该步，避免被后续失败逻辑覆盖。
- 广告救援保留累计时间及救援次数；不将辅助通关混入独立纪录。
- 多星球全景适配关卡边界，画面和粒子仍不参与物理判断。

## 已知限制与需要实机验证

- 自动驾驶只证明路线存在，不等于新手可以同样用时/燃料完成。特别是双星三星路线仍需更熟练的提前对齐；本次记录为二星。
- 已验证单腿断裂补救与单腿迫降两个局部场景，未声称完成“从发射台出发、撞断腿、再迫降”的整段自动回放。
- 真实 Android / iOS 手机的双指延迟、持续运行帧率、音频权限、触感和安全区还需实机验收；浏览器尺寸模拟不能代替实机。
- 简化点接触、离散固定步和弹簧求解保留 v0.4 取舍，并非连续碰撞或软体仿真。极端高速/复杂角度仍需探索测试。
- 数据只在当前浏览器与网址保存，没有跨设备同步；清理站点数据会丢失进度。
- 未接入真实广告、TapTap SDK、在线排行榜或反作弊；没有安装服务或改防火墙。
